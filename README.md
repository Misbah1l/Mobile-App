# Mobile App Development

This repository contains my Android application project developed using Android Studio.

## Project: MyAuthApp

MyAuthApp is an Android application developed using Java and XML layouts.

## Technologies Used

- Android Studio
- Java
- XML
- Gradle

## Project Structure

- `MyAuthApp/` — Contains the Android application project.
- `app/` — Contains the application's source code, resources, and configuration.
- `.gitignore` — Specifies files and folders that Git should ignore.

## How to Open the Project

1. Download or clone this repository.
2. Open Android Studio.
3. Select **Open** and choose the `MyAuthApp` folder.
4. Allow Gradle synchronization to complete.
5. Run the application on an emulator or connected Android device.
